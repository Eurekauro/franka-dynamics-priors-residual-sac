# Historical scientific gate snapshot

`FINAL_GATE.json` is an immutable snapshot of the prior scientific-consolidation gate. Its historical `MP4/GIF_NOT_AVAILABLE` field refers to the evidence available at that gate date and must not be read as a statement about the later Owner-authorized showcase assets.

Current repository/publication status is recorded separately in `GITHUB_PUBLIC_RELEASE_GATE.json`. Neither file changes the frozen scientific results, strict-P5 scope, or post-hoc classification.
