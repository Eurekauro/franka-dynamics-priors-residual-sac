# Artifact availability

`FULL_LOCAL_PROJECT` contains the frozen NPZ priors, 30 SAC policies, P4/P5 records, figures, media, and immutable migration evidence. These roots are intentionally ignored by Git. `GITHUB_PUBLIC_CANDIDATE` contains only tracked source, configuration, documentation, Panda assets, and artifact-free tests; it supports Level A only.

Before publishing artifacts, provide an owner-approved bundle or external source with destination, SHA-256 manifest, license/redistribution decision, and clear missing-artifact errors. The policy corpus is about 106 MB in aggregate; use a release asset, LFS, or controlled external bundle only after approval.
