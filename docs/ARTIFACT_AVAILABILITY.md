# Artifact availability

`FULL_LOCAL_PROJECT` contains frozen NPZ priors, 30 SAC policies, full P4/P5 records, figures, media, and immutable migration evidence. These roots remain intentionally ignored by Git. `GITHUB_PUBLIC_CANDIDATE` contains tracked source, configuration, documentation, Panda assets, artifact-free tests, and Owner-authorized selected figures, aggregate CSVs, GIF, cover, and MP4; it supports Level A only.

The selected showcase assets are documented in `docs/assets/ASSET_PROVENANCE.md` and `THIRD_PARTY_ASSET_MATRIX.csv`. Frozen weights, policies, full episode records, logs, buffers, and archives still require an owner-approved bundle or external source with SHA-256 and distribution decision before any future publication.
